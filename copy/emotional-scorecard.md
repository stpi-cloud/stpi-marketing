# STPi — emotional scorecard & pre-call Diagnosis

Companion to `emotion-engine.md`. Score every sales call within an hour of
hanging up. Review three scored calls a week. A call that "went well" but
scores under 6 will come back as "let me think about it" — find which emotion
never fired and drill that stage.

## The scorecard (1 point each)

| # | Checkpoint | ✓ |
|---|---|---|
| 1 | Prospect said the typing/hunt is the bottleneck **in their own words** | |
| 2 | We agreed the enemy out loud (06:00 queue / 40 tabs / speed beating quality) | |
| 3 | Prospect gave their hours/week and hourly rate — **their** cost number exists | |
| 4 | Asked "12 months of nothing changes?" and heard "worse" (or their version) | |
| 5 | Prospect named their bench: how many candidates wait without a pipeline | |
| 6 | Prospect said what they'd do **first** with the hours back (verbatim noted) | |
| 7 | Demo ran the three scenes in order: card/letter → coverage/caps/purge → their maths + the tap | |
| 8 | Prospect was invited to audit letter vs CV for an invented fact | |
| 9 | Price was framed against one placement / bundle — never "per month" alone | |
| 10 | Close quoted their own words (recap) and ended in silence + a dated next step | |

**Score bands:** 9–10 close or a clean no. 6–8 stalled deal — re-ignite with
the missing emotion (`sales-scripts-emotion.md` §7). ≤5 polite death —
requalify the prospect list, not the script.

## Pre-call Diagnosis (5 minutes, before any call/demo)

```
Prospect: ______________________  Type (solo/studio/agency/centre/NGO): __________
Evidence found (2+ signals, cold-outreach-emotion-rotation.md): _________________
Their public promise (their words): ____________________________________________
Likely dominant emotion (anger / fear / greed): _________________________________
Their enemy, named: ___________________________________________________________
Estimated typing cost: ±___ hrs/week × R___ = ±R______/month (CONFIRM on call)
One placement / bundle is worth: R________  →  covers ±____ months of Solo
Safety proof they'll need most (tap / no-invention / caps / purge / Sovereign): ___
Who else decides (partner/principal/spouse): ____________________________________
Opening line (one true, specific sentence): ______________________________________
```

## Funnel metrics (add to whatever you already track)

- **Evidence rate** — outreach sent with real research vs generic. Generic should trend to 0.
- **Scene completion** — demos that reached Scene 3 (their maths). Below Scene 3, price talk is premature.
- **Close-on-call rate** — demo set up (or tier sold) before hanging up.
- **72-hour first-card rate** — first card landed within 3 days of setup. This is the churn-killer; chase it operationally.
- **7-day upgrade nudge reply rate** — by archetype; tells you which greed currency your market actually wants.
- **30-day refund/cancel rate** — your manipulation detector. If emotion outruns truth, this rises first. When it moves, re-read `emotion-engine.md` §8 before touching any script.

## Weekly 30-minute review

1. Pick 3 calls (one won, one stalled, one lost). Score them.
2. Name the weakest stage across all three. Rewrite exactly one script line for it.
3. Check one number above. If first-card rate slipped, fix onboarding before writing more outreach.
